## Modification Notice

This is an unofficial modified ARM64 build of Tsugaru.

The modifications and additional files in this distribution
provide controller/input support and launcher integration
intended for ARM64 handheld Linux systems, including
configuration through input.cfg.

The modified build has been tested on:

* Powkiddy V90S running KNULLI
* TRIMUI Brick running KNULLI

This distribution is not an official release by CaptainYS.

The original Tsugaru project and its original source code
remain the work of CaptainYS (Soji Yamakawa).

The modifications and additional files created specifically
for the Tsugaru ARM64 Handheld package are covered separately
by LICENSE_Modifications.txt.

FM TOWNS BIOS/ROM files and commercial game software are not
included in this distribution.
